# 敏感模式清单

> 本清单定义 Agent 产出中须扫描与脱敏的敏感信息模式。`scripts/sanitize.py` 与 `scripts/pii_scanner.py` 内置覆盖核心类型，扩展类型由 Agent 在报告层参照本清单补充检测。
>
> - 处置等级：极敏感（阻断）/ 高敏感（脱敏）/ 中敏感（掩码）/ 低敏感（可用）
> - 阻断=是 的类型命中即阻断提交（exit=2）

## 一、个人身份信息（PII）

| 类型 | 正则模式 | 处置等级 | 阻断 | 默认处置 | 内置脚本 |
|------|---------|---------|------|---------|---------|
| 手机号 | `1[3-9]\d{9}` | 高敏感 | 否 | 掩码（前3+****+后4） | sanitize.py / pii_scanner.py |
| 身份证（18位） | `\d{17}[\dXx]` | 高敏感 | 否 | 掩码（前6+********+后4） | sanitize.py / pii_scanner.py |
| 身份证（15位） | `[1-9]\d{7}(0[1-9]\|1[0-2])(0[1-9]\|[12]\d\|3[01])\d{3}` | 高敏感 | 否 | 掩码（前6+*****+后2） | 扩展 |
| 护照号 | `[A-Z]\d{8}` | 高敏感 | 否 | 掩码（首1+******+后2） | 扩展 |
| 港澳通行证 | `[HMhm]\d{8,10}` | 高敏感 | 否 | 掩码（首1+******+后2） | 扩展 |
| 军官证 | `[A-Z]\d{6,8}` | 高敏感 | 否 | 掩码（首1+****+后2） | 扩展 |
| 邮箱 | `[\w.\-]+@[\w\-]+\.[\w.]+` | 中敏感 | 否 | 掩码（首字符+***@域名） | pii_scanner.py |
| 姓名（中文） | 上下文判断（"姓名：""户名："后2-4字） | 中敏感 | 否 | 掩码（首字+**） | 扩展 |
| 地址 | 上下文判断（"住址：""地址："后详细地址） | 中敏感 | 否 | 保留省市，掩码详细地址 | 扩展 |

## 二、账户与资金信息

| 类型 | 正则模式 | 处置等级 | 阻断 | 默认处置 | 内置脚本 |
|------|---------|---------|------|---------|---------|
| 银行卡号 | `\d{16,19}` | 高敏感 | 否 | 掩码（前4+****+后4） | pii_scanner.py |
| 银行卡号（带校验） | Luhn 校验通过的 16-19 位数字 | 高敏感 | 否 | 掩码（前4+****+后4） | 扩展 |
| 存款账号 | `\d{12,19}`（上下文含"账号""账户"） | 高敏感 | 否 | 掩码（前4+****+后4） | 扩展 |
| 信用卡 CVV | `\d{3}`（上下文含"CVV""安全码"） | 极敏感 | 是 | 删除 | 扩展 |
| 信用卡有效期 | `(0[1-9]\|1[0-2])/\d{2}`（上下文含"有效期"） | 高敏感 | 否 | 替换为 **/** | 扩展 |
| 交易金额 | 上下文判断（"金额："后数字） | 中敏感 | 否 | 保留，按场景脱敏 | 扩展 |
| 账户余额 | 上下文判断（"余额："后数字） | 中敏感 | 否 | 保留，按场景脱敏 | 扩展 |

## 三、密钥与凭证

| 类型 | 正则模式 | 处置等级 | 阻断 | 默认处置 | 内置脚本 |
|------|---------|---------|------|---------|---------|
| AWS Access Key | `AKIA[0-9A-Z]{16}` | 极敏感 | 是 | 替换为 ***REDACTED*** | sanitize.py |
| OpenAI/通用密钥 | `sk-[A-Za-z0-9]{20,}` | 极敏感 | 是 | 替换为 ***REDACTED*** | sanitize.py |
| 私钥（PEM） | `-----BEGIN [A-Z ]*PRIVATE KEY-----` | 极敏感 | 是 | 删除整段 | 扩展 |
| JWT Token | `eyJ[A-Za-z0-9_-]+\.eyJ[A-Za-z0-9_-]+\.[A-Za-z0-9_-]+` | 极敏感 | 是 | 替换为 ***REDACTED*** | 扩展 |
| 数据库连接串 | `(mongodb\|mysql\|postgres\|jdbc)://[^\s]+` | 极敏感 | 是 | 替换为 ***REDACTED*** | 扩展 |
| 通用 API Key | 上下文判断（"api_key""apikey""secret"后等号赋值） | 极敏感 | 是 | 替换为 ***REDACTED*** | 扩展 |
| Bearer Token | `Bearer\s+[A-Za-z0-9_-]{20,}` | 极敏感 | 是 | 替换为 ***REDACTED*** | 扩展 |
| 密码赋值 | 上下文判断（"password""passwd""pwd"后等号赋值，非占位符） | 极敏感 | 是 | 替换为 ***REDACTED*** | 扩展 |

## 四、网络与基础设施

| 类型 | 正则模式 | 处置等级 | 阻断 | 默认处置 | 内置脚本 |
|------|---------|---------|------|---------|---------|
| IPv4 地址 | `\d{1,3}(\.\d{1,3}){3}` | 中敏感 | 否 | 掩码（前2段+.*.*） | 扩展 |
| IPv6 地址 | `[0-9a-fA-F:]{2,}(:[0-9a-fA-F]{1,4}){2,7}` | 中敏感 | 否 | 掩码（首组+::ffff） | 扩展 |
| 内网 IP（10./172.16-31./192.168.） | `(10\.\|172\.(1[6-9]\|2\d\|3[01])\.\|192\.168\.)\d{1,3}\.\d{1,3}` | 高敏感 | 否 | 掩码（前2段+.*.*） | 扩展 |
| 生产环境标识 | 上下文判断（"prod""production" + 域名/IP） | 高敏感 | 否 | 掩码 | 扩展 |
| MAC 地址 | `([0-9a-fA-F]{2}:){5}[0-9a-fA-F]{2}` | 低敏感 | 否 | 掩码（前3段+:*:*） | 扩展 |
| 服务器主机名 | 上下文判断（"主机名""hostname"后标识） | 中敏感 | 否 | 掩码 | 扩展 |

## 五、生产数据片段

| 类型 | 识别依据 | 处置等级 | 阻断 | 默认处置 | 内置脚本 |
|------|---------|---------|------|---------|---------|
| 数据库导出（DML） | 含 `SELECT * FROM` + 真实表名 | 极敏感 | 是 | 删除 | 扩展 |
| 数据库导出（DDL） | 含 `CREATE TABLE` + 真实表名 | 极敏感 | 是 | 删除 | 扩展 |
| 生产日志片段 | 含生产环境标识 + 时间戳 + 业务数据 | 极敏感 | 是 | 删除 | 扩展 |
| 脱敏标记缺失的数据 | 含客户字段但无脱敏标记的数据行 | 极敏感 | 是 | 删除 | 扩展 |
| 数据库快照 | 含 `INSERT INTO` + 批量真实数据 | 极敏感 | 是 | 删除 | 扩展 |
| 监控指标导出 | 含生产主机名 + 性能指标 + 时间戳 | 高敏感 | 否 | 掩码主机名 | 扩展 |

## L3 必填深度字段

| 字段 | 要求 | 示例 |
|------|------|------|
| 模式清单覆盖度 | PII/密钥/生产数据三类全覆盖 | 本清单覆盖 6 大类 30+ 模式 |
| 处置等级 | 每类标注极敏感/高敏感/中敏感/低敏感 | 密钥=极敏感，手机号=高敏感 |
| 阻断规则 | 极敏感类阻断=是，其余=否 | 密钥/生产数据/凭证=阻断 |
| 内置脚本覆盖 | 标注每个模式是否内置脚本支持 | 手机号/身份证/密钥=内置，其余=扩展 |
| 规则更新机制 | 月度评审敏感模式清单，新增类型及时入库 | 月度评审记录见脱敏报告 |

## 规则持续更新机制

1. **月度评审**：安全团队按月评审敏感模式清单，纳入新增类型（如新密钥格式、新证件类型）
2. **漏检复盘**：对漏检案例做根因分析，补充模式或收紧正则
3. **误报优化**：对误报高的模式（如银行卡号 `\d{16,19}` 误报订单号）加校验位或上下文判断
4. **版本管理**：模式清单变更须记录版本号、变更内容、确认人
5. **白名单维护**：测试数据/示例值/文档占位符纳入白名单，免脱敏

> 白名单项须标注免脱敏理由，经安全确认后生效。白名单命中率统计见 `templates/sanitization-report.md` 的"白名单命中统计"字段。
