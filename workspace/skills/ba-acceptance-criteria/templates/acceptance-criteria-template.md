## 验收标准

### AC-<序号>-01 <标准标题>

| 要素 | 内容 |
|------|------|
| 前置条件（Given） | <可验证的前置状态，如：用户已登录且当前日累计限额为5000元> |
| 操作（When） | <可观察的操作，如：用户提交调高日累计限额至20000元> |
| 预期结果（Then） | <可验证的结果，如：系统提示"限额调整成功"，当日累计限额更新为20000元> |

**可测试性自检：**

- [ ] 前置条件可构造（数据/状态可准备）
- [ ] 操作可执行（有明确入口与步骤）
- [ ] 预期结果可验证（有明确输出/状态变化/提示信息）
- [ ] 无模糊词（大概/等等/尽快/尽可能）
