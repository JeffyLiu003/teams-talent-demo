## L3 必填深度字段

| 字段 | 要求 |
|------|------|
| 数据准备 | Given前置状态的数据构造方式（含数据来源与构造脚本） |
| 边界值 | min/min-1/max/max+1 用例覆盖 |
| 异常路径 | 接口异常/超时/并发/幂等场景独立验收标准 |
| 追溯矩阵 | AC编号↔US↔REQ↔TC 四向追溯 |
| 幂等性 | 资金类操作重复提交的预期行为 |
| 合规边界 | 监管类需求的限额上限/报送时效验收 |
