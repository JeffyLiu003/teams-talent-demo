# arch-adr-writing 技能

## 概述

本技能用于按标准格式记录架构决策，确保决策可追溯。

## 工作流

1. 识别需要ADR的决策点
2. 按模板编写ADR：背景/问题/决策/备选方案/后果
3. 引用相关设计文档与评审记录
4. 编号归档（ADR-NNN）
5. 关联到设计文档


## 深度档位（L3 实施级）

| 档位 | 要求 |
|------|------|
| L1 | 骨架要点，用于讨论 |
| L2 | 标准评审级（银行生产默认） |
| L3 | 在L2基础上增加以下深度内容（高风险/监管/复杂集成时必用） |

### L3 工作流补充

- L3 ADR增加量化权衡表：成本/性能/运维/审计/风险五维对比
- 记录决策影响与回退路径

### L3 质量门禁

- [ ] 备选≥2
- [ ] 量化权衡表完整
- [ ] ADR关联设计文档与证据

> 主模板含【L3必填】深度字段：`templates/adr-template.md`；详细档位定义见《Skill深度分级规范》。
