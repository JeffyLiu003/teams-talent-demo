# STRIDE检查清单

- [ ] Spoofing：身份伪造（认证/会话）
- [ ] Tampering：数据篡改（完整性）
- [ ] Repudiation：否认操作（审计/日志）
- [ ] Information Disclosure：信息泄露（加密/脱敏）
- [ ] DoS：拒绝服务（限流/容错）
- [ ] Elevation：越权提升（授权/RBAC）

每项需覆盖：认证/授权/数据/输入校验/日志/会话。
