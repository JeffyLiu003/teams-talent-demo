## term_check.py

### 用途
扫描产出文档（需求/设计/测试/代码注释）中的支付领域术语，与内置或外部词汇表比对，检测禁用别名命中、疑似未收录术语，并输出修正建议。确保全流程术语一致，避免"转账/转帐/划账"混用导致的开发误解与对账差错。

### 接口
```
python term_check.py <目标文档.md> [--glossary 词汇表.md] [--json]
```

### 参数
| 参数 | 说明 |
|------|------|
| `target_md` | 目标文档路径（.md / .txt） |
| `--glossary` | 外部词汇表路径（可选，默认使用内置词表）。词汇表为 Markdown 表格，须含"术语"与"别名（禁用）"列 |
| `--json` | 输出 JSON 格式（默认即为 JSON） |

### 退出码
| 码 | 含义 |
|----|------|
| 0 | 通过（无不一致别名，无未收录告警） |
| 1 | 告警（有疑似未收录术语，但无禁用别名） |
| 2 | 失败（命中禁用别名，须修正后方可继续） |
| 3 | 参数错误（文件不存在 / 读取失败） |

> 退出码优先级：禁用别名（2） > 未收录告警（1） > 通过（0）。即同时存在别名违规与未收录告警时，返回 2。

### 检查项
1. **禁用别名检测**：将文档文本与别名映射表比对，命中即报告。别名映射示例：转帐→转账、划账→转账、日限额→日累计限额、核账→对账、流水号→交易号、批量转账→批量代发、国际转账→跨境汇款、保证金→备付金等。
2. **子串排除**：若别名出现位置实际是某个合法术语的子串（如"转账"中包含"账"），则不视为违规，避免误报。
3. **未收录术语检测**：正则匹配含"限额/额度/账[户单]/款"的复合中文词，若既不在术语表也不在别名表中，则标记为疑似未收录，需人工判断后登记或修正。
4. **术语命中统计**：统计文档中已使用的标准术语列表与数量。

### 内置词表
默认内置 20 个核心术语 + 14 组禁用别名映射，覆盖转账/限额/清算结算/对账/冲正/批量代发代扣/跨境汇款/长短款/串户/备付金等核心概念。使用 `--glossary` 可叠加外部词汇表（不覆盖内置，仅追加）。

### JSON 输出示例
```json
{
  "terms_found": ["转账", "单笔限额", "清算"],
  "terms_count": 3,
  "inconsistent": [
    {
      "alias": "转帐",
      "should_be": "转账",
      "count": 1,
      "suggestion": "将 '转帐' 改为 '转账'"
    }
  ],
  "inconsistent_count": 1,
  "suspected_uncataloged": ["日转账额度"],
  "passed": false,
  "exit_code": 2
}
```

### 调用示例
```bash
# 基本校验（使用内置词表）
python skills/bank-domain-payments/scripts/term_check.py 需求说明书.md

# 使用自定义词汇表
python skills/bank-domain-payments/scripts/term_check.py 需求说明书.md --glossary templates/glossary.md --json

# 管道消费（退出码驱动 CI 门禁）
python skills/bank-domain-payments/scripts/term_check.py 设计文档.md && echo "术语一致" || echo "术语不一致，请检查"
```

### 词汇表格式要求
外部词汇表须为 Markdown 表格，包含"术语"列和"别名（禁用）"列：
```markdown
| 术语 | 英文 | 定义 | 别名（禁用） | 来源 |
|------|------|------|-------------|------|
| 转账 | Transfer | 账户间资金划转 | 转帐、划账 | BR-PAY-001 |
| 清算 | Clearing | 批量轧差计算 | - | 央行令〔2018〕第2号 |
```

### 单测对应
`tests/test_scripts.py` 中 `bank-domain-payments/term_check.py` 条目（3 用例）：
- `alias_detected`：含禁用别名"转帐" → exit=2，输出含 `inconsistent`
- `clean_terms`：仅含标准术语"转账" → exit=0，输出含 `terms_found`
- `missing_file`：文件不存在 → exit=3，输出含 `error`
