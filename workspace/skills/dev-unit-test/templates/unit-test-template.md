# 单测结构模板

```text
功能：<被测函数/类>

用例1-正常路径：
  Given <前置状态>
  When  <操作>
  Then  <断言>

用例2-边界路径：
  Given <边界输入>
  When  <操作>
  Then  <边界断言>

用例3-异常路径：
  Given <异常输入>
  When  <操作>
  Then  <异常断言>
```
