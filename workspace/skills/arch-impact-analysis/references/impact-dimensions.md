# 影响维度与分级标准

## 六维影响面

| 维度 | 检查要点 |
|------|---------|
| 代码 | 模块、类、文件、依赖关系 |
| 数据 | 表、字段、数据迁移、兼容性 |
| 接口 | 对内/对外接口、联调方 |
| 配置 | 参数、配置项、环境差异 |
| 文档 | 设计、操作手册、测试文档 |
| 权限 | 角色、权限点、数据访问 |

## 影响级别

| 级别 | 定义 | 处置 |
|------|------|------|
| 高 | 影响核心流程/生产数据/跨系统 | 专项评审+回退演练 |
| 中 | 影响局部功能/次要接口 | 评审+回归 |
| 低 | 无外部影响 | 记录即可 |
