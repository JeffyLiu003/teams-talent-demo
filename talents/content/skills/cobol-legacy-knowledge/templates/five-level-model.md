# 五层业务模型（L1–L5）

| 层级 | 名称 | 内容 |
|------|------|------|
| L1 | 业务模型 | 业务能力、宏观流程、领域边界 |
| L2 | 领域模型 | 业务实体、关系、统一语言 |
| L3 | 流程模型 | 详细流程、活动、业务规则 |
| L4 | 系统模型 | 程序、模块、数据存储 |
| L5 | 实现模型 | 批次作业、调度、运行时拓扑 |

每条事实必须标注证据：程序名/段/行号。

---

## L3 必填深度字段

| 字段 | 要求 |
|------|------|
| 证据 | 程序/段/行引用 |
| 适配 | 岗位消费profile |
