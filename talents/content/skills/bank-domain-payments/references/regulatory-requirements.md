# 监管规则速查

## 1. 限额监管

| 规则 | 来源 | 系统要求 |
|------|------|---------|
| 网银转账单笔5万/日20万 | 《电子支付指引》默认值 | 参数可调，不得超监管上限 |
| 大额交易5万元上报 | 《金融机构大额交易报告管理办法》 | 交易完成触发报送 |
| 客户分级限额 | 行内风险管理制度 | 按客户风险等级动态调整 |

## 2. 反洗钱

| 规则 | 来源 | 系统要求 |
|------|------|---------|
| 大额交易报告 | 央行令〔2018〕第2号 | 单笔/累计≥5万元，T+1报送 |
| 可疑交易报告 | 《金融机构可疑交易报告管理办法》 | 规则引擎实时筛查，人工复核后上报 |
| 黑名单筛查 | 联合国/外交部制裁名单 | 交易前实时比对，命中即阻断 |
| 客户身份识别 | 《反洗钱法》第十六条 | 开户/大额交易前KYC核验 |
| 交易记录保存 | 《反洗钱法》第十九条 | 至少保存5年，不可篡改 |

## 3. 数据安全

| 规则 | 来源 | 系统要求 |
|------|------|---------|
| 个人信息脱敏 | 《个人信息保护法》第五十一条 | 展示时脱敏，存储时加密 |
| 数据分类分级 | 《数据安全法》第二十一条 | 按密级标注与访问控制 |
| 跨境数据传输 | 《个人信息保护法》第三十八条 | 跨境须安全评估或认证 |
| 关键信息基础设施 | 《关键信息基础设施安全保护条例》 | 等保三级以上 |

## 4. 支付清算

| 规则 | 来源 | 系统要求 |
|------|------|---------|
| CNAPS大额实时 | 央行支付系统运行办法 | 工作日8:30-17:00，实时到账 |
| CNAPS小额批量 | 央行支付系统运行办法 | 7×24小时，按场次批处理 |
| 网银互联 | 超级网银规范 | 7×24小时，实时到账，单笔5万 |
| 跨境汇款 | 外汇管理局规定 | 须申报，反洗钱加强筛查 |

## 5. 监管引用规范

在需求/设计文档中引用监管要求时，须使用标准格式：

```
[监管文号] 条款编号 条款摘要
```

示例：
- `[央行令〔2018〕第2号] 第八条 金融机构应当在大额交易发生之日起5个工作日内报送`
- `[《个人信息保护法》] 第五十一条 处理者应当对个人信息采取加密、去标识化等安全技术措施`

> 引用须可追溯至原文，禁止概括性引用（如"根据监管要求"须改为具体文号与条款）。
