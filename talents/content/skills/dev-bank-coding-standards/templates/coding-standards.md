# 编码规范清单（五类）

| 类别 | 检查项 |
|------|--------|
| 命名 | 类/方法/变量命名规范，常量命名，无拼音缩写 |
| 异常 | 禁止吞异常，异常要分级处理，禁止捕获后忽略 |
| 日志 | 关键操作打日志，含入参出参摘要，不含敏感信息 |
| 安全 | 参数化查询，无硬编码密钥，输入校验，防注入 |
| 资源 | 连接/流/锁正确释放，try-with-resources |

| 字段 | 要求 |
|------|------|
| 行级问题 | 文件:行+规则+建议 |
| 工具映射 | SonarQube规则编号 |
