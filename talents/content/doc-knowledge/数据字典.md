## 4. 标识符规则

| 标识符 | 规则 |
|---|---|
| 账户号 | 11 位数字字符串，前导零保留 |
| 客户号 | 9 位数字字符串，前导零保留 |
| 卡号 | 16 位字符型，禁止数值化 |
| 交易号 | 16 位字符型 |
| 日期 | `YYYY-MM-DD` 文本 |

新系统中以上标识符一律使用零填充字符串，**不得使用 `long`**，否则会丢失前导零。

## 5. 数据迁移注意

存量 ASCII 数据文件中的带符号数值字段保留 EBCDIC 过穿孔尾字节：`{` = +0、`}` = −0、`A`–`I` = +1…+9、`J`–`R` = −1…−9。导入前必须按 copybook 逐字段解码。

示例：`00000001940{` → 1940.00；`0000009190}` → −919.00。
