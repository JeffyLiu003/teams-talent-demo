## 2. 易混淆概念

| 术语 / 字段 | 常见误读 | 正确语义 |
|---|---|---|
| `ACCT-CURR-BAL` | 当前可用余额 | **已用额度（欠款）**。可用额度 = 信用额度 − 本字段 |
| `TRAN-CAT-BAL` | 账户余额 | 按账户 + 类型 + 类别的累计发生额，只作计息基数 |
| 账单支付金额符号 | 还款金额应为负数 | 交易金额是**正数**，由程序直接做减法 |
| `CUST-ADDR-LINE-3` | 客户没有城市字段 | 城市就存放在第 3 行地址 |
| `ACCT-CURR-CYC-CREDIT` / `-DEBIT` | CREDIT = 还款，DEBIT = 消费 | 正数（消费）进 CREDIT，负数（退款 / 冲正）进 DEBIT，与字面相反 |
| 授权与交易 | 授权也是一笔交易 | 授权只写挂起授权，**不产生交易记录** |
| 日交易与交易 | 统称“交易” | 前者待入账、可重复投递；后者已入账、唯一键 |
| 欺诈标记 `R` | R = Reject | `R` = **解除欺诈**，与拒绝码无关 |
| Decline 与 Reject | 统称“拒绝” | Decline 发生在授权（`05` + 4 位原因码）；Reject 发生在入账（100–103）。码表不可互换 |
| 过期授权释放额度 | 删除过期授权会自动回补额度 | 存量系统从不冲减信用余额，过期授权永久占用额度；新系统已修复（NR-AUTH-01） |
| 原因码 `0000` | 代表拒绝 | 是**无拒绝原因**，即批准时的缺省值 |
| 类别 `0002` | 类别码全局唯一 | 类型 01 下是预借现金，02 下是电子还款，04 下是线上授权，**必须与类型联合解读** |

## 3. 命名速查

| 前缀 | 含义 |
|---|---|
| `CB*` 程序 | 批处理，如 CBTRN02C（入账）、CBACT04C（计息） |
| `CO*` 程序 | 在线交易，如 COSGN00C（登录）、COPAUA0C（授权） |
| `CV*` copybook | VSAM 记录布局 |
| `CI*` copybook | IMS 段布局 |
| 事务码 `CA` / `CC` / `CT` / `CB` / `CP` | 账户 / 卡与登录 / 交易 / 账单支付 / 授权 |
